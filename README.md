# [웰체크] 국가정책·제도 모니터링 (공개판)

국가정책 및 제도 변화 동향을 수집·분석하고, 웰체크 서비스 영향도와 대응 과제를 통합 관리하는 대시보드의 공개 웹페이지 버전입니다.

- **매일 오전 9시(한국시간)** GitHub이 자동으로 뉴스와 기관 공지를 수집해 `data/feed.json`에 저장합니다.
- 페이지는 GitHub Pages 주소로 **누구나 로그인 없이** 볼 수 있습니다.
- 페이지의 **새로 수집** 버튼을 누르면 GitHub의 수집 작업 화면이 열립니다. 저장소 관리자가 *Run workflow*를 누르면 바로 수집되고, 2~4분 뒤 페이지에 반영됩니다.
- `ANTHROPIC_API_KEY`를 등록하면 수집할 때마다 Claude가 뉴스 동향 요약(의료기관 영향·웰체크 영향·대응 포함)을 새로 씁니다. 키가 없으면 요약만 마지막 것이 유지되고 나머지는 그대로 동작합니다.

## 페이지 구성 (왼쪽 메뉴)

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 시행 일정(D-day), 선제 대응 과제, 영향 매트릭스, 고시 감시, 2027 핵심 수치 |
| 기획·준비 관리 | 1. 검토 대기 → 2. 교육 진행 → 3. 기획 중(달력) → 4. 개발·배포(배포 달력) → 5. 피드백 |
| 실무 정보 | 보건복지부·심평원·건보공단 공지사항 (채용·이벤트 제외) |
| 뉴스 동향 | 뉴스 동향 요약 + 원문 피드 (날짜별·키워드별) |
| 팩트체크 | 보도 수치를 공식 자료와 대조한 결과 |

**기획·준비 관리**는 이 공개판에서도 쓸 수 있지만, 입력한 내용은 **각자 쓰는 브라우저에만** 저장되고 다른 사람과 공유되지 않습니다. 파일 첨부는 링크로만 가능합니다. 팀이 함께 쓰는 기획 관리는 사내 Claude 아티팩트에서 이용하세요.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 대시보드 화면. 검색 키워드 목록(`const CATS`)과 대응 과제·일정도 여기에 있습니다 |
| `scripts/collect.mjs` | 뉴스·기관 공지 수집과 요약 스크립트 |
| `.github/workflows/collect.yml` | 매일 09:00 자동 실행 설정 |
| `data/feed.json`, `data/brief.json` | 수집 결과 (자동 갱신 — 직접 올리지 마세요) |

## 페이지를 새 버전으로 바꿀 때

1. hey-n-y 계정으로 로그인한 브라우저에서 `https://github.com/hey-n-y/health-policy-monitor/upload/main` 을 엽니다.
2. 새 버전의 `index.html`, `README.md`, `scripts` 폴더를 끌어다 놓습니다. **`data` 폴더는 올리지 않습니다.**
3. 맨 아래 **Commit changes**를 누릅니다. 1~2분 뒤 공개 페이지에 반영됩니다.

## 처음 설정할 때 (이미 했다면 건너뛰세요)

1. **저장 권한**: Settings → Actions → General → *Workflow permissions*에서 **Read and write permissions** → Save
2. **웹페이지 켜기**: Settings → Pages → *Deploy from a branch* → **main** / **(root)** → Save
3. **(선택) Claude 요약**: Settings → Secrets and variables → Actions → New repository secret → Name `ANTHROPIC_API_KEY`
4. **첫 수집 시험**: Actions → 뉴스 수집 → Run workflow

## 운영 메모

- **실행 시각**: GitHub 예약 실행은 수 분~수십 분 늦게 시작될 수 있습니다. 페이지의 '마지막 수집' 시각으로 확인하세요.
- **예약 중지**: 저장소에 60일 동안 활동이 없으면 예약 실행이 멈출 수 있습니다. 매일 수집 결과가 커밋되므로 보통은 문제없습니다.
- **수집 실패**: GitHub이 저장소 주인에게 메일을 보냅니다. 모든 검색이 실패하면 기존 데이터는 바뀌지 않습니다.
- **키워드 추가·변경**: `index.html`의 `const CATS = [...]` 한 곳만 고치면 수집 스크립트도 같은 목록을 씁니다.
- **공개 범위**: 인터넷에 공개되는 페이지입니다. 내부 메모나 민감한 내용은 넣지 마세요.
